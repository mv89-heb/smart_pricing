# Smart Pricing — ניהול חיובי מכללה

מערכת Flask לניהול מחירון וחיובים תקופתיים, עם דוח תקופתי, דשבורד אנליטי,
ניהול מוצרים והגדרות מערכת (משתמשים, הרשאות, גיבוי).

## הרצה מקומית

```bash
pip install -r requirements.txt
python app.py
```

האפליקציה תרוץ על SQLite מקומי (`local_products.db`) עם משתמש מנהל ראשוני
`admin` / `password123` (או הערך שהוגדר ב-`ADMIN_BOOTSTRAP_PASSWORD`).
**מומלץ להחליף סיסמה מיד** דרך מסך ההגדרות לאחר ההתחברות הראשונה.

## פריסה לפרודקשן

נקודת הכניסה לפרודקשן היא `wsgi:app` (לא `app:app`) - `wsgi.py` רושם את
נתיבי הדוח/הדשבורד/הגדרות ומזריק את שכבת הניווט המשותפת בנוסף ללוגיקה ב-`app.py`.

```
gunicorn wsgi:app
```

(מוגדר גם ב-`Procfile` לפלטפורמות שתומכות בו, כמו Render.)

ראו `.env.example` למשתני הסביבה הרלוונטיים.

## הרצת בדיקות

```bash
pip install pytest
python -m pytest tests/ -v
```

## מבנה הפרויקט

- `app.py` — מודלים (Product, DailyEntry, ActivityLog, User), אימות/הרשאות,
  ורוב נתיבי ה-API.
- `wsgi.py` — נקודת הכניסה לפרודקשן: מרכיב יחד את `app.py` +
  `period_report.py` (נתיבי עמודים ודוח תקופתי) + `price_sync.py` (סנכרון
  מחירים ותיקוף מוצר בחיוב) + `performance.py` (אינדקסים) + שכבת ניווט.
- `templates/` — עמוד לכל מסך (`period_report.html` הוא דף הבית).
- `static/table-sort.js` — כלי מיון עמודות גנרי, משותף לכל הטבלאות במערכת.

### עקרון מרכזי: מחיר קפוא (`unit_price`)

כל חיוב שומר את מחיר המוצר **בזמן ההזנה** (`DailyEntry.unit_price`), נפרד
מהמחיר הנוכחי במחירון (`Product.price`). זה מכוון: עדכון מחיר במחירון לא
משנה למפרע דוחות היסטוריים. חיובים חדשים תמיד משתמשים במחיר הנוכחי.
